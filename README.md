# Squad Manager Pro

this is a mobile app game Design the Squad screen and Player Profile screen for the mobile football management game "Manager Legacy".

Use the existing design system and visual style. Do not redesign the design system or Home screen.

1. SQUAD SCREEN

Create a professional squad-management interface.

Show the starting XI on an interactive football pitch.

Include:

Formation

Starting players

Substitutes

Player overall ratings

Fitness

Morale

Form

The manager should be able to quickly understand:

Best players

Weak positions

Tired players

Players in poor form

Squad depth

Add controls for:

Formation

Tactics

Squad list

Training

Player elements should clearly look interactive and lead to the player's profile.

Keep the layout mobile-friendly and avoid overcrowding.

2. PLAYER PROFILE

Create a detailed player profile screen that opens when a player is selected.

Show prominently:

Player image

Name

Position

Overall rating

Potential

Age

Show core attributes:

Pace

Shooting

Passing

Dribbling

Defending

Physical

Also show:

Fitness

Form

Morale

Professionalism

Personality

Market value

Salary

Contract length

Create a "Development" section showing:

Current overall

Potential

Development progress

Current training focus

Create a "Contract" section with:

Weekly salary

Contract expiry

Transfer value

Make young high-potential players visually interesting without making the interface flashy.

The player profile should communicate that player development is one of the core mechanics of the game.

Important:

Use fictional players.

Keep the interface premium and realistic.

Maintain strong information hierarchy.

Do not make it look like an e-commerce product page.

Do not create backend functionality.

Do not redesign previously approved components.

Mobile portrait only.

Focus ONLY on Squad and Player Profile.

This project is a standalone Manager Legacy game application.
